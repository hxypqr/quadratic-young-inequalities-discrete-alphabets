# Quadratic Young Inequalities on Discrete Alphabets

Research repository for the manuscript **“Quadratic Young Inequalities on
Discrete Alphabets: Exact Small Models and Multiscale Rigidity”** by Xiyu Hu.

The repository is intended to keep the manuscript, supporting research notes,
references, and future formalization work in one version-controlled place.

## Repository structure

- `paper/` — canonical LaTeX source and the latest compiled manuscript.
- `formalization/` — roadmap and, later, proof-assistant source files.
- `notes/` — research notes, calculations, and proof-development records.
- `references/` — reading notes and metadata for related work.

## Manuscript

- Source: [`paper/main.tex`](paper/main.tex)
- Current PDF: [`paper/main.pdf`](paper/main.pdf)

The source is currently self-contained. Run `pdflatex main.tex` twice from the
`paper/` directory to refresh the table of contents, references, and links.
