# References and reading notes

manuscript currently keeps its bibliography directly in `paper/main.tex`.

| Citation key | Authors and title | Relevance | Public link | Notes status |

Do not store copyrighted publisher PDFs unless redistribution is permitted.
Prefer stable public links, arXiv identifiers, DOIs, and original reading notes.
